Reaction Defense

너는 원점(0, 0)에 선 전자 e⁻. 몰려오는 불안정한 입자들을 화학 반응식으로 막아내자. 계수가 맞아야 발사되고, 반응 종류마다 효과가 달라.

입력

  • 화면 자판이나 실제 키보드 둘 다 돼요. 원소 기호 뒤의 숫자는 자동으로 아래 첨자, 맨 앞 숫자는 계수가 돼요.
  • 화살표는 → 키, 키보드에선 Tab - = 아무거나.
  • 전하는 자판의 ²⁺ 키, 키보드에선 ^ 다음 숫자와 부호 (예: ^2+).
  • 원소 기호는 대소문자 구분: CO(일산화 탄소) ≠ Co(코발트).
  • 계수는 가장 간단한 정수비로. 같은 웨이브에서 같은 식을 반복하면 위력이 줄어요.
